# Security Policy

## Supported Versions

We actively maintain and provide security patches for the latest version on the default branch.

| Version | Supported          |
| :------ | :----------------- |
| Latest  | Yes |
| < 1.0   | No                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project (including ROS 2 communication nodes, MAVLink telemetry streams, or Ground Control Station endpoints), please follow responsible disclosure:

1. **Do not create public GitHub issues or discussions** for security vulnerabilities.
2. Report the vulnerability privately via **[GitHub Private Vulnerability Reporting](https://github.com/danMoksh/jatayu/security/advisories/new)** or by emailing **mokshdandotiya@gmail.com**.
3. Please include:
   - A description of the vulnerability and its attack vector.
   - Minimal reproduction steps, launch configurations, or packet traces.
   - Potential impact on physical flight safety or GCS integrity.

## Response SLA

- **Initial Acknowledgement**: Within 48 hours
- **Triage & Assessment**: Within 5 business days
- **Fix / Remediation**: Safety and flight-critical issues are prioritized immediately.
